# `reference-sources/` — licensed open-source engineering references

**Purpose:** preserve selected upstream source examples, license text, provenance and Stockland adaptation contracts alongside the local application.

## Included collection

`OPEN_SOURCE_REFERENCE_KIT/` contains:

- selected MIT-licensed X POS source modules and original license;
- upstream repository, branch and commit provenance;
- source register and source-selection notes;
- Stockland adaptation mapping and contracts for product variants, inventory, POS release and offline behavior;
- acceptance scenarios for porting useful patterns into the Stockland application.

The reference collection uses Frappe/ERPNext Python and TypeScript. The Stockland application uses Node.js, SQLite and browser JavaScript. The reference material is a separately licensed learning and adaptation library; Stockland runtime files remain under `src/` and `public/`.

See [open-source provenance](../docs/OPEN_SOURCE_PROVENANCE.md) and the [reference kit README](OPEN_SOURCE_REFERENCE_KIT/README.md).

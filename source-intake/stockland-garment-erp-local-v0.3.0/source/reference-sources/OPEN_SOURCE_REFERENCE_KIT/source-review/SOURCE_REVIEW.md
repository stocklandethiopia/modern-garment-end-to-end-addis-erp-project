# Open-source source selection and license register

This document records the repositories reviewed for Stockland's garment retail, wholesale, inventory and ERP reference library. The source register identifies the license declaration observed for each project and its role in the engineering collection.

## Selected implementation snapshot — X POS (MIT)

https://github.com/kodlyft/xpos

The selected source snapshot contributes concrete examples for POS stock availability, deterministic inventory row locking, configurable barcode parsing, durable invoice submission, offline checkout policy and corresponding regression tests. The exact MIT license and upstream commit are preserved beside the selected source files.

Upstream snapshot: `develop` at `4f65d681f766c0dcc73fcbb2debc7bd105c8223f`. The source files are maintained under `reference-sources/xpos/` at their upstream-relative paths.

## Clothing retail workflow reference — POS System (Apache-2.0)

https://github.com/mayphyusinthant/pos-system

The project README documents clothing retail, multi-store inventory, employee roles, customer/supplier records and daily sales reporting. It informs the retail workflow checklist and source comparison.

## Garment business-domain reference — W and B Clothing (MIT)

https://github.com/itzcheh1ru/w-and-b-clothing-garment-management-system

The repository provides garment-oriented entity and workflow vocabulary for suppliers, customers, employees, stock and orders. Its MIT declaration is recorded in the source register.

## Mobile Odoo client reference — Mobo POS (Apache-2.0)

https://github.com/mobo-open-source/mobo_pos

This Flutter client documents a mobile Odoo POS integration pattern, account switching, POS session control and device-oriented UI practices.

## Textile ERP reference — ParaLogicTech/textile (GPL-3.0)

https://github.com/ParaLogicTech/textile

This Frappe textile application is catalogued with its GPL-3.0 license family for future architecture and license-compatibility decisions.

## Garment factory frontend reference — SLIIT-Y3-S2 (MIT)

https://github.com/SLIIT-Y3-S2/Garment-Factory-Management-System-Frontend

The project is catalogued as a frontend-oriented garment factory workflow and screen reference.

# License and redistribution records

## Included X POS source

The selected files from `kodlyft/xpos` are distributed under the MIT License declared by the upstream repository. The complete license text is preserved in `reference-sources/xpos/LICENSE` and upstream provenance is recorded in `reference-sources/xpos/ORIGIN.md`.

Redistribution of the selected files and derivative versions preserves the upstream copyright/license notice. Modified files should identify the changes, and independent third-party dependencies and assets retain their own licenses.

## Other reviewed projects

`SOURCE_REGISTER.csv` records the license observed for each reviewed repository and whether source bytes were selected for this kit. Links retained for discovery remain attributed to their original projects. A repository without an explicit license entry is handled according to its published repository terms and is not classified as public domain.

## Dependency and asset records

The Stockland reference kit does not include dependency directories, vendor bundles, third-party font files, screenshots, logos, compiled binaries, secrets or sample credentials. The upstream X POS files reference Frappe/ERPNext and TypeScript application services; those environments are independently maintained.

Before distributing any future combined or derivative release, maintain the full dependency and asset license inventory for the selected release contents.
